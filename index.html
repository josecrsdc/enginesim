En modo Test los pedales simulan la conducción. En modo GPS el acelerador y el freno se deducen de tu velocidad real; el pedal solo sirve para revolucionar el motor estando parado. Para usar el modo GPS, permite el acceso a tu ubicación cuando el navegador lo solicite.
